WEEK 02 · FLASK & DATABASES

01 / Visitor counter

Flask handles requests and MariaDB stores the visitor count. In database I have table called messages which has columns for id, name, message and timestamp for posted message. App.py inserts written message with name to a database and delivers existing messages. For visit counter there is another table with two columns: id and total.

Total visits: {{ visits }}

The count is stored in the database and persists when the application restarts.

02 / Application logic

Nginx forwards requests to the Flask application running through Gunicorn. Flask communicates with MariaDB and returns the generated HTML page.
